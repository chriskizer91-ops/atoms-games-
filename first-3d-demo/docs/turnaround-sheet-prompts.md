# Creature Catch 3D: Turnaround Sheet Prompts

Nov 2, 2026 · @Chris

## How to use these

Each prompt asks for a turnaround sheet: one character drawn from every side, in the game's own pixel style, so the 3D model can match the art exactly. They're reference for modeling only and never show up in the game.

1.  Use the same chat that made the original Creature Catch art.

2.  Attach the character's existing sprite (the repo path is under each prompt). Start the message with the line the polish pack used: "Using the attached sprite as reference for the character's colors, outfit and proportions, draw:" Then paste the prompt.

3.  Keep the solid magenta \#FF00FF background, as in the extra and polish prompts.

4.  Name each file with the **bold** name above its prompt, for example turnaround-drizzlon.png, and send them to me in our chat. A zip is fine.

Start with sections 1 and 2; they fix the most. If a sheet comes back with a different pose in each view, ask again with: "the exact same pose in every view, as if it is standing on a slowly turning turntable".
