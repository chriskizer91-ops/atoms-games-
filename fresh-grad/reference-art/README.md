# reference-art/

Reference boards from `IMAGE_PROMPTS.md` (`RF-*`, `CH-01/02/06/07`) — buildings, interiors, cast lineups, light and season studies.
They are not loaded by the game; they are looked at while drawing and polishing the procedural art so each place and person reads as distinct.
