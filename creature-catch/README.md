# Creature Catch

A Game Boy Advance–style monster-catching JRPG. Walk through tall grass, battle wild creatures, and catch them with purple-and-blue capture cubes.

Status: design phase. No code yet.

## Layout

- `docs/` design documents and image prompts. Read `creature-catch-handoff.md` first; where it disagrees with `creature-catch-design-doc.md`, the handoff wins.
  `creature-catch-extra-prompts.md` covers everything the first four prompt files did not (vampire line, effects, UI, portraits, interiors, outposts, gates, world map).
- `art/` generated sprites, tilesets, and backgrounds (incoming).
