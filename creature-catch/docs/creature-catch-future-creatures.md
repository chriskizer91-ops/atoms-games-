# Creature Catch: Possible Future Creatures

> **Not in any build yet.** These 19 creatures came from a ChatGPT design pass ("Beyond the Moonlit Trails"). They're the ones that don't repeat an idea already in the game or in the expansion (`creature-catch-expansion-image-prompts.md`). The original pictures were deleted after this file was written, so every prompt below describes the design on its own, in the game's style.

## Where they could go

A post-game side quest, the **Far Isles**: a chain of islands past Lantern Isle, reached by boat once the expansion is done. These creatures live only there, so filling in their Creature Log pages is the goal. A suggested split:

| Island | Creatures |
|---|---|
| **Brineglass Shoals** (sea glass, pearls, coral) | Brinibble, Razoray, Pearlpip, Nacrelark, Anemimpi, Coralith, Saltuft, Saltruff |
| **Cinderbloom Isle** (volcanic flowers, ember beasts) | Scovip, Scoviper, Ashquill, Basalisk, Hearthorn |
| **Hushbell Heights** (wind, clouds, quiet) | Thistlepip, Galethistle, Spindrift, Spiracene, Loomur, Auralope |

The types are suggestions. Change them when the creatures are added.

## How to use these prompts

- For the closest match, attach one of the game's own creatures (for example `tuftail.png`) and start with: **"Match the art style of the attached image exactly: same outline weight, shading, colors and level of detail."**
- For an evolved form, attach the first form you made and start with: **"Using the attached sprite for colors, markings and design, draw its evolved form:"**
- Save each picture with the creature's name as the file name (for example `brinibble.png`).
- Everything is on solid magenta except Anemimpi, which is pink-red and goes on white.
