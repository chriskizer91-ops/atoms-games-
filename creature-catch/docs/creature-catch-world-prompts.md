# Creature Catch: World, NPC, and Environment Prompts

Companion to the creature prompts file. Every prompt is self-contained, so copy one and paste it into the image generator.

**Tips for consistent results**
- Generate one section per chat so the style stays matched.
- Tilesets work best when you ask for "a grid of separate tiles on a white background," then slice them in a pixel editor (Aseprite, Piskel, or LibreSprite all work).
- Image generators are weak at true seamless tiling. If a tile has visible seams, add: "must tile seamlessly on all four edges, no border, no vignette."
- Generators also struggle with exact pixel sizes. Treat sizes as a style hint and resize or clean up afterward.
- Keep text out of art. Add names and menu labels in your game engine.
