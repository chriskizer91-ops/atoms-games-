# Creature Catch: Evolution Image Prompts

These are the evolved forms. The first two prompt files only covered the base creatures, so this file fills in the rest of each evolution line: **6 starter evolutions + 18 regular evolutions = 24 sprites**.

## How to keep evolutions looking related to their base form

**Best method (reference image):**
1. Generate the base sprite from the creature prompts file.
2. Attach that image in the same chat.
3. Add this line at the start of the evolution prompt:
   > Using the attached sprite as reference for colors, markings, and character design, draw its evolved form:

**No-reference method:** every prompt below repeats the base creature's key traits (colors, markings, accessories) so the generator carries them over.

**Rules of thumb**
- Evolved forms should fill more of the 64x64 canvas than base forms.
- Keep the same palette family as the base form, but add one or two new accent colors.
- Keep the same outline weight, shading style, and white background so everything matches in-game.
- Generate each starter line together using the line-up prompts below, for the best consistency.
