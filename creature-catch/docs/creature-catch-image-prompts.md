# Creature Catch: Image Prompts

Every prompt below is self-contained. Copy one, paste it into the image generator, and you're done.

**Tips for consistent results**
- Generate in one chat so the generator keeps the same style.
- For matching looks, ask for a "sprite sheet" and paste 4 to 6 prompts at once, with the line: "Draw each as a separate sprite in a grid, same style, same scale."
- If the generator makes the art too detailed, add: "very low resolution, chunky pixels, retro handheld game."
- If the background isn't clean, add: "solid pure white background, no gradient."
