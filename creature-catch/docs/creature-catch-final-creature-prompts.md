# Creature Catch: Final Creature Prompts

The last new creatures for this stage of the game, picked in the Evolution Lab. **39 pictures** for his Yes votes, plus **6 optional ones** for his Maybe votes (only make those if he decides yes). The family's own five designs (the ice cream pup's three forms, Clovetastical and Hoppin Pop) are already done: they were cut from the drawings.

Each creature's name, types, level and lore are in `creature-catch-lore-bible.md`, under the place where it lives.

## How to use this file

1. **Attach the creature it grows from.** Every entry names the picture to attach (they're in `art/creatures/`, or save them from the Field Guide). For a third form, attach both earlier forms if the generator takes two pictures.
2. **Copy the prompt** and paste it in. Each one starts by telling the generator to use the attached picture.
3. **Save it with the name in bold,** lower case: `bloomstag.png`, `queenbuzz.png` and so on. Anything with the name in it works (`bloomstag-v2.png` is fine).
4. **Backgrounds:** solid magenta, except the three pink creatures (Shellcastle, Drillotl, Constellastar), which go on white so the pink doesn't blur into the background.
5. **Keep effects attached** to the creature (a glowing lamp, a storm cloud it rides). The game adds sparkles, splashes and glows itself, so loose specks around a sprite end up as stray dots.
6. **Stay in one image chat per place** (the sections below), so a place's creatures match each other. Hand them over in batches, in any order.

**His ideas are built in.** Where he wrote an idea in the Evolution Lab, the prompt follows it (the yeti with bigfoot colors, the moss lich, the gem-covered lizard, the colors-flipped pufferfish, the muddy furry pig, the owl that looks like an oak tree, and the Moonlynx cub).
